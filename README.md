# Clock-music-vizualizer-for-YNDX-00020
# clockviz

clockviz — это легкий эквалайзер / визуализатор спектра (4-столбчатый level meter) для LED-дисплея Яндекс Станции Мини 2.

Программа считывает сырой PCM-аудиопоток (S16_LE) из stdin, выполняет 512-точечное БПФ (FFT), сворачивает 8 логарифмических частотных полос (40 Гц .. 7.6 кГц) в 4 цифры циферблата и отображает каждую цифру как 3-сегментную шкалу (d -> g -> a, снизу вверх) с плавной регулировкой яркости.

## Особенности

* Адаптивный алгоритм: Использует динамический диапазон с плавающим пиком (dB scale under decaying running peak) и адаптивный диапазон на цифру (tau ~3 с).
* Быстрый отклик: Мгновенный отклик на пики (fast attack) и спад в 250 мс (release).
* Умный перехват дисплея: Автоматически подменяет системные часы через bind-mount во время воспроизведения и возвращает стандартное отображение времени, если музыка молчит более ~5 секунд.
* Безопасность системных вызовов: Отсутствует clock_gettime и другие вызовы, вызывающие дамп нераспределенных syscalls в ядре Linux 4.9 Станции Мини 2.
* Защита от блокировок: Поддерживает файл блокировки /tmp/clockviz.lock. При вызове нескольких аудиопотоков только один управляет экраном, а остальные сбрасываются без блокировки плеера.

## Установка и интеграция (ALSA)

В репозитории уже содержится готовый собранный бинарный файл `clockviz` для архитектуры Яндекс Станции Мини 2.

### 1. Размещение файлов

1. Скопируйте готовый бинарник `clockviz` в каталог `/data/opt/clockviz` на устройстве и сделайте его исполняемым:
   ```bash
   chmod +x /data/opt/clockviz
   ```

2. Поместите скрипт настройки `clockviz-setup.sh` в `/data/opt/clockviz-setup.sh` и сделайте его исполняемым:
   ```bash
   chmod +x /data/opt/clockviz-setup.sh
   ```

### 2. Применение конфигурации ALSA

Скрипт `clockviz-setup.sh` идемпотентен (безопасен для повторного запуска). Он модифицирует конфигурационный файл ALSA `/etc/asound.conf`, оборачивая исходное устройство `dmix_spk` и перенаправляя аудиопоток через pipe в `clockviz`:

```bash
/data/opt/clockviz-setup.sh
```

Рекомендуется добавить запуск `clockviz-setup.sh` в скрипты автозапуска системы до запуска демона `quasar`.

## Использование и параметры

Формат запуска через stdin:

```bash
arecord -t raw ... | ./clockviz [-c channels] [-r rate] [-b maxbright] [-R] [-n]
```

### Параметры командной строки

| Флаг | Описание | По умолчанию |
| :--- | :--- | :--- |
| `-c` | Количество аудиоканалов во входном потоке | `2` |
| `-r` | Частота дискретизации (кратна 16000, например 16000, 48000) | `16000` |
| `-b` | Максимальная яркость сегментов (от `1` до `255`) | `255` |
| `-R` | Развернуть порядок цифр (если басы отображаются справа, а не слева) | `Выкл` |
| `-n` | Не перехватывать часы через bind-mount (режим тестирования) | `Выкл` |

### Переменные окружения

* `LEDDIR`: Путь к sysfs-директории светодиодов (по умолчанию `/sys/class/leds`).
* `VIZDEBUG`: Если задано, выводит текущие значения столбиков в `stderr`.

## Сборка из исходников

Если вы хотите пересобрать проект самостоятельно, используйте ARM кросс-компилятор (например, `arm-linux-gnueabihf-gcc`):

```bash
arm-linux-gnueabihf-gcc -O2 -std=c99 clockviz.c -o clockviz -lm
```

## Структура сегментов индикации

Каждая из 4 цифр LED-индикатора использует три горизонтальных сегмента для отображения уровня громкости полосы:

```
    --- (a)  <- Верхний уровень
    --- (g)  <- Средний уровень
    --- (d)  <- Нижний уровень
```
